## B. Interfaz XML de CVA (implementación real sobre el esqueleto)

**Configuración** (`cva_feed.rs`, `settings.ts`): `FeedConfig` pasa a `{ cliente: String }` (número de cliente; la auth es por IP). La URL base es constante del módulo; los parámetros se agregan por consulta. Tarjeta de Ajustes renovada: campo **"Número de cliente CVA"** + recordatorio **"Da de alta tu IP en el portal de CVA"** + nota de horario 19:01–08:59. (Las llaves viejas endpoint/client_key se retiran; se agregaron ayer y no hay datos reales.)

**Cliente HTTP + parser** (`cva_feed.rs`, nueva dependencia `quick-xml`):
- `build_url(cliente, marca, grupo, clave, codigo)` con `%` como comodín; `sucursales=1&promos=1&subgpo=1` siempre.
- GET con `ureq` (patrón de `ai.rs`) → parseo de `<item>` a `CvaItem { clave, codigo_fabricante, descripcion, grupo, subgrupo, marca, precio, moneda, promo?, sucursales: Vec<(almacén, cantidad)> }`.
- Monedas: "Dolares"→USD, "Pesos"→MXP. Sucursales: cada elemento (`RETAIL_CDMX`, `CENTRO_DE_DISTRIBUCION_MEXICO`, `VENTAS_*`, …) se registra como almacén del catálogo (`warehouses`, auto-alta con `catalog_id`; clave snake_case).
- Fuera de horario: si la respuesta viene vacía y la hora local está fuera de 19:01–08:59, el mensaje lo explica ("CVA devolvió 0 artículos — fuera del horario el servicio siempre devuelve vacío").
- `query(sku)` real: `codigo=<sku>&sucursales=1&promos=1&subgpo=1`, devuelve cotizaciones parseadas.

**Clasificación e importación** (nuevo mapeo en `cva_feed.rs` + reuso de `suppliers.rs`/`store.rs`):
- Grupo→tipo: gabinetes→Case, monitores→Monitor, mouse→Mouse, procesadores→Cpu, tarjeta madre→Motherboard, teclado y mouse→KeyboardMouseKit, teclados→Keyboard, video→Gpu, memorias→Ram, discos duros→Storage, energia→Psu. Coincidencia insensible a mayúsculas/acentos por comodín.
- Subgrupos excluidos del ensamble (memorias USB/flash/lectores; UPS/no-break/extensión/regulador…) + heurística de `solucion` → kind **«otro»** (decisión 1).
- Marca: `canonicalize_brand` recorta «(…)» (decisión 3).
- Precio efectivo = `PrecioDescuento` si hay promo, si no `precio` (decisión 2). `on_promotion = true` si trae promo.
- Stock: `stock_ensamble` = RETAIL_CDMX + CENTRO_DE_DISTRIBUCION_MEXICO; `stock_individual` = **suma de todas las sucursales** (venta individual acepta cualquier sucursal). El `disponible` plano se ignora (en tu ejemplo trae 0 con CDM=856).
- Promo → nueva tabla (abajo). El import reusa `ParsedProduct`/`apply_import` con supplier="cva" y **sin barrido** (es parcial); el barrido de ausentes solo aplicará en el import completo (`grupo=%`) que queda listo por comando pero **sin botón aún** — es el de la ventana nocturna que crearía el catálogo completo con todas las categorías/marcas.

**Comando** `import_catalog_cva(grupos: Vec<String>, marca: Option<String>)`: importa los grupos pedidos y devuelve el **mismo resumen que el XLSX** (updated/inserted/total + informe de ensambles vigentes afectados, reutilizando `snapshot_live_items`/`out_of_stock_report`). El resultado incluye conteo por grupo — si un nombre de grupo no coincide, se verá en 0 importados.

## C. Normalización (migración v10)

- **Nueva tabla `offer_promos`** — entidad propia 1:1 con la oferta vigente: `(sku, supplier) PK/FK → product_offers ON DELETE CASCADE`, `clave, descripcion, vencimiento, precio_descuento, moneda, disponible, updated_at`. La promo depende de (sku, proveedor) al momento de la importación; separarla evita mezclar la entidad promoción en `product_offers` (mantiene 3FN; sin JSON nuevo). Un re-import CVA refresca o limpia la promo del SKU importado; un import de arroba jamás toca la promo CVA (clave por proveedor).
- `warehouses` crece por catálogo (auto-alta de sucursales) — sin cambio de esquema.
- Marcas canónicas por regla de recorte — `brands` sigue UNIQUE sin duplicados; si apareciera un caso que la regla no resuelva, se agregará después una tabla de alias.
- Ningún flujo nuevo introduce JSON ni repeticiones: las existencias por sucursal ya viven en `offer_stock` (1FN/3FN intactas), las notas de venta ya congelan sus renglones.
